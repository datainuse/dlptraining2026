{{% notice %}} ### Create a custom label and apply it to your device. <br><br>Create the label in the format of first initial last name – ex. jsmith.

{{% /notice %}}

1. Click “Admin settings” in the left pane of the management console.

    {{< figure src="case1_1.png" alt="case1_1" >}}

2. Click “Labels” and then “Create new custom label.”
  
    {{< figure src="case1_2.png" alt="case1_2" >}}

3. Enter your first initial last name in the “Name” text box (ex. John Smith will enter “jsmith”).

    {{< figure src="case1_3.png" alt="case1_3" >}}

4. Click "Nodes" in the left pane of the management console.

    {{< figure src="case1_4.png" alt="case1_4" >}}

5. Click your node name to open the node details page and click the edit pencil next to "Labels."

    {{< figure src="case1_5.png" alt="case1_5" >}}

6. Select the label you created earlier in this use case and click "Assign labels."

    {{< figure src="case1_6.png" alt="case1_6" >}}
